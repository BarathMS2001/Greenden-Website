# 🌿 GreenDen - Online Plant Store
 
GreenDen is a responsive and modern plant-selling website built using **HTML5** and **Tailwind CSS**. The website provides an elegant and user-friendly platform for customers to explore plants, browse products, and contact the business easily.
 
This project was developed in Visual Studio Code and focuses on implementing modern frontend design principles using Tailwind CSS utilities such as **Flexbox, Grid, Spacing, and Text Utilities**.
 
---
 
## 🚀 Features
 
- Responsive design for mobile, tablet, and desktop devices
- Modern and clean user interface
- Attractive Home page with hero section
- Product showcase page with responsive layouts
- Contact page with inquiry form
- Built using Tailwind CSS utility classes
- Fast, lightweight, and easy to navigate
- Organized and reusable code structure
 
---
 
## ✨ Tailwind CSS Concepts Practiced
 
During the development of GreenDen, the following Tailwind CSS concepts were implemented:
 
### Flexbox Utilities
- `flex`
- `justify-center`
- `justify-between`
- `items-center`
- Responsive Flexbox layouts
 
### Grid Utilities
- `grid`
- `grid-cols-*`
- Responsive product card layouts
- Grid spacing management
 
### Spacing Utilities
- Padding (`p-*`)
- Margin (`m-*`)
- Gap (`gap-*`)
- Consistent layout spacing
 
### Text Utilities
- Text sizing (`text-sm`, `text-lg`, `text-xl`)
- Font weight (`font-bold`, `font-semibold`)
- Text alignment
- Typography styling
- Responsive text design
 
### Responsive Design
- Mobile-first approach
- Responsive breakpoints:
- `sm:`
- `md:`
- `lg:`
- `xl:`
